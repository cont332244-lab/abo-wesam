# دفتر التحضير الإلكتروني

تطبيق أندرويد لإعداد خطة الدرس تلقائيًا من عنوان الدرس، بواجهة عربية.

## ⬇️ تنزيل التطبيق

### [📥 اضغط هنا لتنزيل التطبيق (APK)](https://github.com/cont332244-lab/abo-wesam/actions/runs/40021849417)

إذا لم يبدأ التنزيل مباشرةً، افتح صفحة البناء أعلاه، ثم من قسم **Artifacts** اضغط على **lesson-planner-apk**، وافتح ملف ZIP واستخرج منه `app-debug.apk` وثبّته على هاتفك.

[رابط تنزيل ملف البناء ZIP مباشرةً](https://api.github.com/repos/cont332244-lab/abo-wesam/actions/artifacts/12531675124/zip)

> ملاحظة: روابط ملفات Artifacts في GitHub مؤقتة الصلاحية. إذا انتهت صلاحية الرابط، افتح صفحة Actions وابحث عن أحدث بناء ناجح ثم نزّل Artifact باسم `lesson-planner-apk`.

## الميزات
- إنشاء تحضير الدرس انطلاقًا من عنوانه.
- واجهة عربية مناسبة للاستخدام على الهاتف.
- يتضمن التحضير أهداف الدرس، والتمهيد، وخطوات التنفيذ، والتقويم، والواجب.
- توقيع التعاون: معلم دمج، بالتعاون مع أبو محمد وأبو عبدالله وعصام، منصة معلمي الجزيرة السورية.
